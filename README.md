# Pronovo — независимый концепт-портфолио

Статическая адаптивная страница на русском языке, созданная как независимый дизайн-концепт. Это не официальный сайт Pronovo и не подтверждение фактических услуг, условий или логистики компании.

## Демонстрационные материалы

Карточки автомобилей, цены, характеристики, наличие, калькулятор с условной наценкой +20% и карта маршрута — вымышленные элементы интерфейса. AUTOPAPA отмечена только как точка, присутствующая в видеореференсе; страница не утверждает наличие партнёрства, адреса или точки выдачи.

Для актуальной информации используйте [официальный сайт Pronovo](https://pronovoavto.ru/) и [карточку компании в 2ГИС](https://2gis.ru/irkutsk/firm/70000001089072638).

## Локальная проверка

Откройте `index.html` в браузере. Страница не требует сборки или сторонних библиотек. Каталог поддерживает фильтры, поиск, сортировку и демонстрационные направления; калькулятор, прокрутка и мобильное меню работают на клиентской стороне.

Запустите проверки командой `node --check script.js && node --test tests/behavior.test.cjs`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет JavaScript и структуру страницы для pull request и публикует содержимое корня репозитория на GitHub Pages при push в `main`. Перед первой публикацией администратор репозитория должен открыть **Settings → Pages** и выбрать **Build and deployment → Source: GitHub Actions**. Токен workflow не имеет прав администратора для создания Pages site; после этой однократной настройки workflow сможет публиковать сайт.
