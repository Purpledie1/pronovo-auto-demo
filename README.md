# Pronovo — независимый концепт-портфолио

Статическая адаптивная страница на русском языке для независимого визуального концепта Pronovo, сервиса подбора и заказа автомобилей в Иркутске. Это не официальный сайт компании.

## Демо-данные и источники

Вымышленные карточки автомобилей, их характеристики, цены и наличие, а также наценка +20% в демонстрационном калькуляторе служат только для показа интерфейса. Они не являются реальными предложениями или тарифами компании.

Контактный телефон и направления подбора (Азия, Европа, США) сверены с публичными источниками:

- [Официальный сайт ProNovo](https://pronovoavto.ru/)
- [Карточка Pronovo в 2ГИС](https://2gis.ru/irkutsk/firm/70000001089072638)

## Локальная проверка

Откройте `index.html` в браузере. Страница не требует сборки или сторонних библиотек. Каталог фильтруется по типу, региону и поисковому запросу; калькулятор и мобильное меню работают на клиентской стороне.

## GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет JavaScript и структуру страницы для pull request и публикует содержимое корня репозитория на GitHub Pages при push в `main`. Настройка Pages выполняется в Actions через `configure-pages`.
